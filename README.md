# AgentOS Research Workspace

This repository hosts research artifacts for AgentOS. The active work is Paper 1, **BudgetFlow: Value-Aware Budget Governance for Agent Tasks**.

BudgetFlow studies **Batch-Level Task Budget Allocation** for multi-step agent tasks under a shared hard budget. The paper evaluates value-aware budget governance on SWE-bench-style verified coding tasks and reports Resolved Rate, Total Resolved Value (TRV), and TRV per Dollar.
