# Practice-Feedback Targets for BudgetFlow / AgentOS (July 2026)

Date context: current date is 2026-07-08. The goal here is not maximum prestige, but a realistic first submission that can yield useful reviewer feedback within roughly the next month.

## 1. AgenticDev 2026

- Venue: **AgenticDev 2026: International Workshop on Agentic AI for Next-Generation Software Development** (co-located with **ASE 2026**)
- Deadline: **2026-07-15, AoE (UTC-12), 11:59 PM**
- Submission type / page limit: **Full papers up to 10 pages**, **short papers up to 5 pages**, **demo/tool papers up to 5 pages**; up to 2 extra reference pages
- Submission system: **HotCRP** - <https://agenticdev2026.hotcrp.com>
- Fee: **No submission fee stated**; registration info deferred to ASE 2026
- Fit: Very strong for **AI agents, coding/testing/maintenance agents, orchestration, human-in-the-loop development, trustworthiness, benchmarking, and empirical evaluation**
- Why this is a practice-feedback target: The workshop explicitly welcomes **short, vision, and demo/tool** submissions, which makes it a good place to submit an early BudgetFlow / AgentOS paper for feedback rather than a fully mature flagship paper
- Risks / notes: Very tight deadline; workshop scope is broad, so the paper should clearly foreground the **agentic SE** contribution rather than only cost optimization
- Sources:
  - <https://conf.researchr.org/home/ase-2026/agenticdev-2026>
  - <https://agenticdev2026.hotcrp.com>

## 2. MAS-GAIN 2026

- Venue: **MAS-GAIN 2026: Multi-Agent Systems and Generative AI for Automated Software Engineering** (co-located with **ASE 2026**)
- Deadline: **2026-07-17, AoE (UTC-12), 11:59 PM**; abstract deadline **2026-07-10**
- Submission type / page limit: **Regular papers up to 8 pages**, **short papers up to 4 pages** (including references); workshop welcomes **research papers, experience papers, and tool presentations**
- Submission system: **EasyChair** - <https://easychair.org/conferences/?conf=masgain2026>
- Fee: **No submission fee stated**; accepted papers require at least one author registration
- Fit: Strong for **multi-agent coding systems, agent routing/orchestration, task-based agent selection, resource usage optimization, verification/validation of AI-generated code, human-agent collaboration, and empirical evaluations**
- Why this is a practice-feedback target: This is a practical workshop venue for an early systems paper, especially if framed as a **multi-agent / routing / tool / experience** contribution instead of a polished theory paper
- Risks / notes: The workshop leans somewhat more toward **multi-agent systems** than pure coding-agent evaluation, so the paper should make the software engineering and evaluation story concrete
- Sources:
  - <https://conf.researchr.org/home/ase-2026/mas-gain-2026>
  - <https://easychair.org/conferences/?conf=masgain2026>

## 3. RASE 2026

- Venue: **RASE 2026: Reliable and Trustworthy Automated Software Engineering** (co-located with **ASE 2026**)
- Deadline: **2026-07-24, AoE (UTC-12), 11:59 PM**
- Submission type / page limit: **Regular papers up to 8 pages**, **short/demo papers up to 4 pages**, **position papers up to 2 pages** (including references)
- Submission system: **EasyChair** - <https://easychair.org/conferences/?conf=rase2026>
- Fee: **No submission fee stated**
- Fit: Strong for **trustworthiness of AI-based code generation/repair, empirical evaluation of AI-assisted development tools, metrics and benchmarks, and benchmarking trustworthy automated SE systems**
- Why this is a practice-feedback target: Good fit if the first BudgetFlow / AgentOS paper emphasizes **evaluation quality, reliability, cost-aware control, and benchmark-driven evidence**; the short/demo/position formats lower the bar for an initial feedback-seeking submission
- Risks / notes: Less directly branded around "agent systems" than AgenticDev or MAS-GAIN; the paper should explicitly connect BudgetFlow to **trustworthy automated SE**
- Sources:
  - <https://conf.researchr.org/home/ase-2026/rase-2026>
  - <https://easychair.org/conferences/?conf=rase2026>
