CCF推荐国际学术刊物目录CCF发布计算领域高质量科技期刊分级目录　　　
第七版《中国计算机学会推荐国际学术会议和期刊目录》正式发布
阅读量:147548 收藏本文
2025年4月，CCF决定启动新一轮中国计算机学会推荐国际学术会议和期刊目录（以下简称《目录》）调整工作并委托CCF学术工作委员会组织实施。本次目录调整的总体原则是：在既有基础上进行微调；领域划分方式保持不变，期刊和会议的推荐类别体系保持不变，并在同等情况下优先支持国内期刊。目录仍分为A、B、C三类，其中，会议论文指“Full paper”或“Regular paper”（正式发表的长文），对于会议上其他形式发表的论文如Short paper、Demo paper、Technical Brief、Summary、Findings以及作为伴随会议的Workshop等不计入目录考虑的范围。需要说明的是，一些出版社和学术社团编发的magazine (杂志) 未纳入本“目录”的推荐期刊列表中。

经过前期的充分讨论和论证后，CCF学术工作委员会于2025年5月正式向各专委会、CCF高级以上会员（含高级）征集调整建议。2025年7月向Elsevier征集调整建议；2025年10月向IEEE CS、ACM等学术机构征集调整建议。目录的调整建议评审会议于2026年1月11日在北京以线下方式召开，并得到初审结果。2026年1月27日，CCF理事长会议在北京组织了对初审结果和原列表中有异议会议和期刊的审议会议，确定了本次目录的修订结果。

本次目录调整共收到来自30个CCF专业委员会、138位CCF高级及高级以上会员（含14位会士）和其他学术机构提交的169项提案，涉及会议提案104项，涵盖82个会议；涉及期刊提案65项，涵盖55个期刊。在两次会议的审议过程中，专家们都对提案进行了充分的讨论、审议和投票，形成了最终的结果。相较2022年更新的上一版目录，此次《目录》（第七版）新增期刊14个，会议23个；升级期刊6个，会议5个；移除会议1个，降级会议2个，降级期刊1个；更名会议2个。

在确定《目录》的过程中，专家们既考虑了会议和刊物的影响力，也考虑了不同领域间的大致平衡；评审原则兼顾稳定和活力。对于计算机这样一个发展迅速而又覆盖面甚广的学科而言，期刊和会议的数量和影响力本身就处在不断变化之中，《目录》力求反映这些变化，不可能面面俱到，难免有缺憾，只能通过定期更新加以改进。CCF欢迎业界专家对该《目录》提出建议和意见，以便今后修订参考。

必须指出的是，中国计算机学会认为，学术成果的形式多种多样，不仅仅是论文，（开源）软件、系统、专利、标准等都是成果的形式。本《目录》是CCF认为值得计算机界研究者们发表研究成果的一个推荐列表，其目的不是作为学术评价的依据，而仅作为CCF的推荐建议供业界参考。由于领域的交叉和视角的差异，同一刊物/会议在不同领域存在认识上的差异是正常的，本列表也只代表了CCF对这些会议和刊物的推荐建议。此外，刊物和会议的影响力并不直接和发表在其上的单一论文的影响力发生联系，因此不建议任何单位将此《目录》简单作为学术评价的依据。如果由于将此《目录》作为学术评价的依据而引起纠纷，本学会不承担任何责任。

在2026年3月5日至3月12日公示期间，CCF学术工作委员会邮箱（academic@ccf.org.cn）共收到107封问题反馈邮件，其中对于网址/名称/出版社勘误/更新类问题均已完成核实与修正。对于部分涉及合并会议或期刊的反馈，学术工委将在后续工作中另行研讨并制定相应处理方案。对于本次目录评审结果存在异议的申诉意见，将作为下一版目录更新评审的参考文件。需要特别说明的是，涉及目录具体使用场景的问题（如项目申报、成果评价等）不属于学会业务范畴。

此次《目录》修订工作是参与建议的CCF各专业委员会、CCF会员以及评审专家们共同努力的结果，评审期间得到了国内外众多专家学者的支持，提出了宝贵的建议并提供了翔实的数据，在此致以诚挚的谢意。

USENIX Symposium on Operating Systems Design and Implementation (OSDI)
A
关注操作系统设计与实现。

ACM Symposium on Operating Systems Principles (SOSP)
A
聚焦操作系统原理。
操作系统领域的**奠基性顶级会议**，历史悠久，声誉卓著。与OSDI齐名，共同代表着系统软件研究的最高学术殿堂。
International Conference on Architectural Support for Programming Languages and Operating Systems (ASPLOS)
A
跨越体系结构、编程语言和操作系统等多个领域的综合系统会议。
系统领域的“四大”顶级会议之一，以其**交叉学科**的特色著称，影响力广泛。每年录取约100篇论文，但投稿量巨大，竞争激烈。
USENIX Annual Technical Conference (USENIX ATC)
A
涵盖计算机系统技术的广泛领域。
系统技术领域的**顶级综合性会议**，历史悠久。接收论文数量相对较多（约60篇以上），但因涵盖方向广，竞争同样非常激烈。
USENIX Conference on File and Storage Technologies (FAST)
