§5 · Paper scope

论文边界

本文明确覆盖

  • 单一预算主体：多路并发 workflow 共享一池预算与后端 RPM / 并发配额；账本、准入、结算、ZombieDetector、多 WF 调度属本文 runtime 命题。
  • 决策单位：每步 LLM 调用 + 全局预算池状态；评测常以 SWE-bench Verified 批量并发 + 固定总预算等为场景。

本文不 Claim / 留作扩展

  • Multi-tenant：跨团队预算与 SLA — 自然续作（对齐 §8 叙事第二阶段）。
  • 非 GPU serving 独占：不取代 Athena-Serve / vLLM 侧 KV / batch 全集最优；本文为 workflow 花费治理与步骤配额。
  • ZombieDetector：运行时止损构件，可做消融；非独立 RL/ML 主贡献。
  • 成本模型：不绑定 SKU；抽象 dollar / token 计价即可复现结论。
