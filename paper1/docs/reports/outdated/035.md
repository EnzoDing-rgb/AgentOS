## CLI Commands

### `create --issue-id ID --prompt-file PATH`

Reads a markdown prompt file and creates the workflow directory:

```bash
PYTHONPATH=src python3 -m budgetflow.run_autoresearch \
  create --issue-id 042-fix-bug --prompt-file /tmp/my-prompt.md
```

Writes: `state.json`, `worker_prompt.md`, `codex_review.md` (placeholder), `final.md` (placeholder), `attempts/001/worker_output.md` (placeholder).

### `run --issue-id ID [flags]`

Executes one step of the workflow lifecycle. Three modes:

| Flag | Behavior |
|------|----------|
| `--dry-run` | Write prompts/state to disk, skip Worker, print DRY-RUN banner |
| `--manual` | Write prompts/state, print prompt/output/review paths for manual execution |
| `--worker-cmd CMD` | Shell out to CMD with `{prompt}` and `{output}` placeholders substituted |
| *(none)* | Default: manual mode (same as `--manual`) |

Pause condition flags (any trigger pauses the workflow):

```
--paid-3x10 P T    # e.g. --paid-3x10 3 10
--northstar-change
--large-refactor
--data-migration
--swebench-docker
--higher-risk
```

Exit codes: `0` = ok/running/complete, `2` = paused.

### `status --issue-id ID`

Prints workflow status line with issue_id, status, attempt count, dry_run/manual flags. Returns exit code 1 for nonexistent workflows.

### `list`

Scans `.autoresearch/workflows/` and prints a table with ISSUE, STATUS, ATTEMPT, PAUSED columns plus summary counts at the bottom.

### `mark-complete --issue-id ID`

Transitions workflow to `complete`, writes `final.md` summary.

### `mark-failed --issue-id ID [--reason TEXT]`

Transitions workflow to `failed`. Reason is logged to stdout.

## Worker Bridge

The `--worker-cmd` accepts a shell command template with `{prompt}` and `{output}` placeholders:

```bash
PYTHONPATH=src python3 -m budgetflow.run_autoresearch \
  run --issue-id 042-fix-bug \
  --worker-cmd "python3 -m budgetflow.solve_issue {prompt} {output}"
```

The coordinator sets `worker_fn` to a shell-out callable. On exit code 0: status → complete. Nonzero: status → failed (retryable up to max_retries).

Tests use fake commands (`echo`, `exit 1`) — no real agents called.
