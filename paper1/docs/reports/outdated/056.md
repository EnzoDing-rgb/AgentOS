## 4. Bugs Found

### 4.1: BFC Conservation Lockout on High-Value Tasks (REPRODUCED 3x)

BFC on sympy-16988 (value=0.329) fails at 7 turns with `stagnation_repeat_command`, cost $0.033. This is the THIRD experiment showing this pattern:
- 055_3x3_v2: FAIL $0.028 7t
- 055_3x5_v2: task not reached (starvation)
- 056_5x1_v1: FAIL $0.033 7t

The conservation factor (`1.0 + max(0, budget_pressure - 0.3) * 1.5`) progressively locks out T3 as the shared budget depletes, preventing effective work on high-value tasks that appear later in the task order.

### 4.2: BO T3 Hang on sympy-20212

BO on sympy-20212 hung at 33 turns, T3, GPT-5.4, with the gold file found (`sympy/core/power.py`) but unable to produce a valid patch. The agent spent 1000+ seconds at 121s per step — possibly a provider-side stall on GPT-5.4 via aicode007. Same step repeated for ~8 minutes with `active_elapsed_s=121s` (constant — meaning the LLM response never returned).

This is a provider-level issue, not a BudgetFlow bug. But it prevented BO from reaching the highest-value task (sympy-16988), making the BO comparison incomplete.
