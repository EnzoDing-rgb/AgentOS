## Dispatch Wrapper Design

```python
# scripts/autoresearch_worker_dispatch.py
# Reads prompt, checks for dispatch marker:
#   <!-- WORKER:fake -->  → fake worker (no API, no cost)
#   <!-- WORKER:api -->   → thin API worker (real API call)
# Default (no marker): API worker
```

This avoids the problem of "one worker-cmd doesn't fit two profiles" without
adding per-issue worker command support to the goal-loop. The dispatch marker
is an HTML comment so it doesn't affect prompt content.
