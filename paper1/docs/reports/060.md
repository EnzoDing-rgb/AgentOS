## Bugs Fixed

1. Per-task summary totals now show planned cap (`per_task_cap × completed_rows`) instead of comparing strategy spend to a single row cap.
2. Batch footer now displays `per_task_cap` from per-task mode, not the shared frozen tight cap.
3. LLM timeout is configurable via `BUDGETFLOW_LLM_TIMEOUT_S` and defaults to 90 seconds.
4. Timeout exceptions abort tenacity retry so provider fallback can happen quickly.

060 itself exposed the footer display bug after the run completed. The raw JSONL is valid; historical summary was not edited.

## Remaining Risks

- BO's 16988 failure is protocol/extract failure, so the comparison is not a pure capability result.
- BFC still shows repeated exploration and late rescue on 16988. Anti-spin and rescue timing need more work before larger runs.
- This remains local-harness evidence. Official SWE-bench Docker audit is still required before paper headline claims.
- The task pool is still too SymPy-heavy. Add one new repo/category as an infra audit before running a paper-scale dataset expansion.
