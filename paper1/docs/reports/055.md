## 1. Executive Summary

Phase Y implements BudgetFlowValueAware (BFV) — a value-aware routing policy that scales stage weights by a task_value multiplier, making T3 access easier for high-value tasks and harder for low-value tasks.

**Verdict: BFV outperforms both BO and BFC on resolved value per dollar (Yield per Dollar) and is the only strategy to resolve the highest-value task.** In the primary 3-task experiment (055_3x3_v2), BFV achieves 3/3 unique tasks (100%) with Yield per Dollar=1.110 vs BFC 2/3 Yield per Dollar=0.664 vs BO 2/3 Yield per Dollar=0.363. Row-level totals across both experiments: BFV 6/6, BFC 5/6, BO 4/6 (note: 2 tasks overlap between experiments, so row counts inflate unique-task counts). Proxy noise analysis confirms BFV winner stability at 96-100% even at ±50% noise.

## 2. Design

### ValueAwareSelector (new in selector.py)

Extends BudgetFlowSelector directly (not ConservativeSelector). Applies both value-aware scaling AND budget conservation:

```
value_multiplier = clamp(task_value / median_task_value, 0.5, 2.0)
effective_w_i = w_i * value_multiplier
conservation = 1.0 + max(0, budget_pressure - 0.3) * 1.5
effective_threshold = upgrade_threshold * conservation
```

- Higher task_value → higher multiplier → lower effective threshold → easier T3 access
- Lower task_value → lower multiplier → higher effective threshold → harder T3 access
- When all tasks have equal value (multiplier=1), behavior = ConservativeSelector
- Multiplier clamped to [0.5, 2.0] — max 4x difference between high and low value tasks

### ConservativeSelector (unchanged)

Value-blind. Does not accept `task_value`. Has no `last_multiplier`. Conservation factor only.

## 4. Value-Aware Routing Evidence

### 4.1: Multiplier Drives T3 Allocation

| Task Value | Multiplier | BFV Cost | BFV T3% | Resolved |
|-----------|------------|----------|---------|----------|
| 0.059 | 0.50 | $0.100 | 17% | Yes |
| 0.066 | 0.50 | $0.036-0.079 | 8-17% | Yes |
| 0.097 | 0.50 | $0.109-0.129 | 13-17% | Yes |
| 0.329 | 1.48 | $0.279 | 32% | Yes |

Clear gradient: multiplier 0.50 for below-median tasks, 1.48 for the high-value outlier. T3 usage increases with multiplier.

### 4.2: BFC's Value-Blind Conservation Backfires

On sympy-16988 (value=0.329), BFC spent only $0.028 across 7 turns before stagnating. The conservation factor (budget_pressure × 1.5 multiplier) made T3 escalation progressively harder as the shared budget depleted, preventing effective work on the task. BFV's value_multiplier of 1.48 counterbalanced this, enabling $0.279 of productive T3 investment.

### 4.3: Trace Fields

All BFV turn traces include `task_value`, `task_value_multiplier`, and `value_aware_active=True`. BFC and BO traces exclude these fields (`value_aware_active=False`).

## 5. Proxy Noise Robustness

100-trial analysis on 3x3 v2 data:

| Noise | BFV Yield per Dollar Winner | BFV Value Winner |
|-------|----------------|-----------------|
| ±0% | 100% | 100% |
| ±10% | 100% | 100% |
| ±25% | 100% | 100% |
| ±50% | 96% | 100% |

BFV's advantage is robust — even at ±50% value noise, BFC wins Yield per Dollar only 4% of the time and never wins on total resolved value.

## 6. Tier 1 / Tier 2 Verdicts

### Tier 1 (value-driven allocation across tasks): SUPPORTED

BFV resolves 6/6 tasks including the highest-value task (0.329) that both BO and BFC fail. Value multiplier correctly directs more budget (10×) and more T3 capacity (32% vs 8%) to high-value tasks. All evidence is from non-equal value matrix (unsolved_difficulty), satisfying Tier 1 evidence requirements.

**Caveat:** 6-task sample is small. The 3x5 experiment did not reach its highest-value tasks due to budget exhaustion. Larger-scale validation needed.

### Tier 2 (routing heuristic reduces waste): SUPPORTED

BFC already demonstrates that conservation reduces wasteful T3 usage (Yield per Dollar 0.741 vs BO 0.473). BFV adds value-awareness on top (Yield per Dollar 0.977) by allowing high-value tasks to bypass conservation when the value justifies it.
