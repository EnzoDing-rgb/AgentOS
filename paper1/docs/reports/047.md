### A.2 Extraction Logic

Two regex patterns, applied in order:

1. **Quoted paths** (`_QUOTED_PATH_RE`): Extracts paths with file extensions from
   single/double-quoted strings. Supports spaces in paths (e.g.,
   `cat 'src/foo bar.py'` → `src/foo bar.py`). Glob patterns (`*`, `?`) excluded.

2. **Unquoted paths** (`_UNQUOTED_PATH_RE`): Matches paths with known extensions
   using lookahead trailing boundary (doesn't consume the separator, so adjacent
   paths all match). Quoted substrings stripped first to prevent fragment matches.

Supported commands: sed, cat, grep, rg, find, ls, python, pytest, and any other
bash command containing paths with recognized extensions.

### A.3 Trace Field

New field in every turn trace:
```json

```
Stable-sorted, deduplicated. Empty list when no recognizable paths.
