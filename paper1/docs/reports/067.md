## Infra Fix Found During Review

The compact checker originally reported `HARNESS SEVERITY: blocking=1` even though the row was a normal failed/no-patch row, not an unreliable pass.

Root cause: `build_harness_trust()` treated missing harness evidence on failed rows as if it made evaluation unreliable. That is wrong. PASS rows require full pass evidence; FAIL rows without a patch are incomplete/warn, and FAIL rows with `fail_after=fail` are trusted failures.

Fix:

- `HarnessEvidence` now distinguishes pass-complete evidence from evaluated-complete evidence.
- no-patch FAIL is non-blocking incomplete evidence.
- patch-evaluated FAIL with `fail_after=fail` is a trusted failure.
- resolved rows with missing pass evidence remain blocking.

After the fix, the checker reports:

- rows=9
- pass=6
- fail=3
- suspicious_pass=0
- no_trace=0
- no blocking harness severity
- harness trust: trusted=6, trusted_fallback=2, incomplete=1
