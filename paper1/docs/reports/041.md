## Architecture

```
goal-loop
├── load goal
├── for step in 1..max_steps:
│   ├── run_goal() → process one pending/failed issue
│   ├── handle goal status (paused/complete/failed/review_required)
│   ├── if running: deterministic review on processed issue
│   │   ├── PASS → mark complete, continue
│   │   ├── WARN → write owner_decision.md, return 2
│   │   └── FAIL → retry or write owner_decision.md, return 1
│   └── write goal summary
└── return 1 (max steps exceeded)
```
