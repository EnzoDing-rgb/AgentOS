### 1.1 BudgetMemory integration (`run_mini_swe_compare.py`)

4 new CLI flags:
- `--budget-memory PATH[,PATH...]` — load BudgetMemory from JSONL files
- `--disable-budget-memory` — explicitly disable
- `--budget-memory-dry-run` — compute estimates, print comparison table, exit (no API)
- `--budget-memory-gate-only` — load + validate + print diagnostics, exit (no API)

**Default: OFF.** No effect on existing experiments unless `--budget-memory` is explicitly passed.

Behavior:
- Gate-only: validates file existence, prints record/task/repo counts, sys.exit(0)
- Dry-run: loads tasks + auto-budget, prints `auto_cap vs bm_cap` per task, sys.exit(0)
- Normal mode: loads BudgetMemory, computes per-task estimates via cascade. If auto-budget is NOT enabled, BudgetMemory estimates become the per-task caps. If auto-budget IS enabled, auto-budget caps take priority. Hard budget (`--per-task-cap`) always highest priority.

New record fields (per row):
- `budget_memory_enabled`, `budget_memory_source`, `budget_memory_estimated_budget`
- `budget_memory_predicted_cost`, `budget_memory_confidence`, `budget_memory_reason`
- `budget_memory_hard_budget_used`, `budget_memory_risk_multiplier`, `budget_memory_applied`

### 1.2 Failure subtype (`failure_classification.py`)

New `classify_failure_subtype(record, *, axis=None, stage=None) -> str`:
- pass → `pass`
- budget_fail + progress → `budget_exhausted_after_progress`
- budget_fail + no progress → `budget_exhausted_no_progress`
- model_fail + localization → `loc_model_fail`
- model_fail + repair → `repair_model_fail`
- model_fail + validation → `validation_model_fail`
- protocol_fail → `extraction_protocol_fail`
- harness_fail → `harness_incomplete`
- infra_fail / routing_fail → `provider_or_parser_error`

`build_verdict()` now includes `failure_subtype` key. `_run_one()` writes it to JSONL.

### 1.3 Compact audit + offline_replay extensions

`check_run_observability.py`:
- `build_compact_audit()` collects `fail_subtypes` counter
- `format_compact_audit()` shows FAILURE SUBTYPES line

`offline_replay.py` — 4 new sections:
- **BUDGET DRY-RUN**: BudgetMemory estimates vs actual costs
- **FAILURE SUBTYPES**: subtype distribution for non-resolved rows
- **FALLBACK AUDIT**: submitted vs fallback patch comparison
- **INCOMPLETE FAIL BREAKDOWN**: no_patch_fail / harness_incomplete_fail / expected_fail_incomplete

### 1.4 Fallback patch audit (`observability.py`)

New `audit_fallback_patch(record) -> dict`:
- `fallback_patch_exists`, `fallback_patch_lines`
- `submitted_patch_exists`
- `submitted_vs_fallback`: same / different / no_submission / no_fallback / no_patch / unknown
- `fallback_audit`: clean / warn / blocking

### 1.5 Incomplete FAIL classification (`observability.py`)

New `classify_incomplete_fail(record) -> str`:
- `no_patch_fail`: no patch extracted at all
- `harness_incomplete_fail`: patch exists but harness evidence incomplete
- `expected_fail_incomplete`: explicit fail_after=fail or model_patch=fail
- `not_applicable`: PASS or not incomplete
