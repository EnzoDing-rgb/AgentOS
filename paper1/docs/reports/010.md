## P0-1: API Pricing Calibration

### Root Cause

| Tier | Model | Hardcoded (in/token) | Real (in/token) | Hardcoded (out/token) | Real (out/token) | Ratio |
|------|-------|---------------------|-----------------|----------------------|------------------|-------|
| T1 | qwen3-coder-flash | $0.0005 | $0.000000055 | $0.002 | $0.000000276 | ~7,200× |
| T2 | qwen3-coder-plus | $0.004 | $0.000000552 | $0.012 | $0.000002207 | ~5,400× |
| T3 | GPT-5.4 | $0.006 | $0.0000025 | $0.018 | $0.000015 | ~1,200× |

**Real pricing sources**:
- T1/T2: DashScope (阿里云百炼) — qwen3-coder-flash ¥0.0004/千in, ¥0.002/千out; qwen3-coder-plus ¥0.004/千in, ¥0.016/千out (0–32K context)
- T3: aicode007 GPT-5.4 ~$2.50/1M in, ~$15.00/1M out

**Impact on routing ratios**: T3/T2 was 1.5× in hardcoded, actually 4.5× input / 6.8× output. Previous routing was too aggressive in escalating to GPT-5.4.

### Fix

Updated `backends.py`, `auto_budget.py`, `tests/test_auto_budget.py` with real per-token USD pricing. Cleaned auto-budget memory (polluted by old units + resolved=None bug).

## P0-3: Worktree Crash

### Root Cause

`_remove_worktree` had no error recovery when `git worktree remove --force` exited non-zero. Stale worktree metadata in `.git/worktrees/<name>` survived cleanup, causing `git worktree add` to fail with exit code 128 on next run.

### Fix (`local_harness.py:_remove_worktree`)

Added three-level cleanup:
1. `git worktree remove --force` — primary path
2. If failed: nuke `.git/worktrees/<name>` metadata directory + `git worktree unlock` + retry remove
3. `shutil.rmtree` filesystem cleanup regardless of git state
4. `git worktree prune` always runs at end

## P0-4: resolved=None in Auto-Budget Memory

### Root Cause

`_write_budget_memory` used `record.get("resolved")` which is always None in JSONL output. `bool(None)` = `False` → all PASS records classified as `not_enough_evidence` or `likely_underbudget`.

### Fix

Changed to `bool(record.get("harness_resolved"))` in `run_mini_swe_compare.py:781`.
