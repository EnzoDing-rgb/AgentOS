Executed outcome:

- All four strategies reported 0/6 verified resolved, so raw T1 NVRV and RVPD were 0.
- This must not be used as evidence that BFV/BFC are weaker than BO: replaying a
  submitted 13480 BFV patch after harness isolation changed it from harness FAIL
  to resolved PASS.
- Root cause: local SymPy harness pytest imported host optional dependencies
  (`opik`, `tensorflow`/`keras`/`pandas`/`scipy`) with a broken NumPy ABI. The
  failure was an infra contamination, not a model/routing outcome.
- Fix direction: isolate pytest plugin autoload, treat broken SymPy optional
  dependency imports as unavailable in ephemeral harness worktrees, and keep
  host-dependency-contaminated runs out of default Routing Memory.
- Remaining real signal after replay: some patches, such as 18835 and 14317,
  still fail true task tests after isolation. Next diagnostics should focus on
  repair/validation quality and stop rules, but only after no-paid harness gates.
