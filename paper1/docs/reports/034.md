### Coordinator API

```python
from pathlib import Path
from budgetflow.autoresearch_coordinator import AutoResearchCoordinator

# Initialize — paper1_root is the only required arg.
c = AutoResearchCoordinator(
    paper1_root=Path("paper1"),
    git_root=Path("paper1"),   # default: same as paper1_root
    tmp_root=Path("/tmp"),     # default: /tmp
    max_retries=2,             # default: 2
)

# Create a workflow from a Codex-approved issue.
state = c.create_workflow(
    "042-fix-bug",
    "# Fix the sympy print bug\n\nApply the patch and verify with pytest.",
    dry_run=False,
    manual_mode=False,
)
# Writes:
#   .autoresearch/workflows/042-fix-bug/
#     state.json
#     worker_prompt.md
#     codex_review.md       (placeholder)
#     final.md              (placeholder)
#     attempts/001/
#       worker_output.md    (placeholder)

# Run one step — checks pause conditions, writes attempt files.
state = c.run(state=state)  # starts attempt 1

# After Worker completes, mark done or failed.
c.mark_complete(state)
c.mark_failed(state, reason="budget_exhausted")

# Check status.
c.print_status("042-fix-bug")
```

### Pause Conditions

All seven conditions from `autoresearch_workflow.md` implemented:

| Condition | Trigger | Key |
|-----------|---------|-----|
| Paid 3x10+ | `paid_experiment_scale=(3, 10)` | `paid_3x10_or_larger` |
| NorthStar change | `northstar_change=True` | `northstar_or_metric_change` |
| Large refactor | `large_refactor=True` | `large_runner_workflow_harness_storage_refactor` |
| Data migration | `data_migration=True` | `delete_or_migrate_experiment_data` |
| SWE-bench Docker | `swebench_docker=True` | `official_swebench_docker_run` |
| Higher risk | `higher_risk=True` | `materially_higher_cost_runtime_or_rollback_risk` |
| Retry exhausted | attempt > max_retries (auto) | `retry_exhausted_after_2_attempts` |

Paused workflows stay paused until the owner or Codex explicitly overrides.

### Retry Policy

- Default `max_retries=2`.
- When a workflow fails (`status="failed"`), `run()` increments attempt count.
- Attempt 3 (exceeds max_retries) triggers `RETRY_EXHAUSTED` pause condition.
- Each attempt has its own directory: `attempts/001/`, `attempts/002/`, `attempts/003/`.
- The coordinator does NOT retry automatically — the caller decides whether to call `run()` again.

### On-Disk Guarantee

Every coordinator interaction writes to disk immediately:
- `state.json` — updated on every status transition
- `worker_prompt.md` — written on workflow creation
- `attempts/NNN/worker_output.md` — placeholder created, caller fills content
- `codex_review.md` — placeholder created, Codex fills content
- `final.md` — written on `mark_complete()`

No in-memory-only state. Workflow can resume after crash by loading `state.json`.

## Review Fix (2026-06-05)

**Bug:** `ArtifactPolicy._is_allowed_autoresearch_path` accepted `program.md`, `agents/`, and `issues/` under `.autoresearch/` but rejected all `workflows/` files. This violated the hard rule that every interaction lands on disk and accepted stages must be recoverable — workflow state, prompts, reviews, and outputs could not be checkpointed.

**Fix:** Added `_is_allowed_workflow_path` whitelist to `ArtifactPolicy` in `autoresearch_guard.py`. Allowed durable workflow files:

| Path | Allowed? |
|------|----------|
| `.autoresearch/workflows/<id>/state.json` | YES |
| `.autoresearch/workflows/<id>/worker_prompt.md` | YES |
| `.autoresearch/workflows/<id>/codex_review.md` | YES |
| `.autoresearch/workflows/<id>/final.md` | YES |
| `.autoresearch/workflows/<id>/attempts/<NNN>/worker_output.md` | YES |
| `.autoresearch/workflows/<id>/attempts/<NNN>/worker_output.log` | YES |
| `.autoresearch/workflows/<id>/attempts/<NNN>/random.tmp` | NO |
| `.autoresearch/workflows/<id>/log.md` (high-churn) | NO |
| `.autoresearch/workflows/<id>/` (dir itself) | NO |
| `data/runs/*` | NO (unchanged) |
| `src/*` | NO (unchanged) |
