### Failure detail

```
RuntimeError: AICODE007_API_KEY, DASHSCOPE_API_KEY is missing.
  Add it to the repo root .env file.
```

Root cause in `adapter/mini_swe_proxy.py:347-356`:
```python
self._api_keys = {config.api_key_env: os.environ.get(config.api_key_env)
                  for config in TIER_CONFIGS.values()}
missing_keys = sorted({
    TIER_CONFIGS[b.name].api_key_env
    for b in routing.backends
    if b.name in TIER_CONFIGS and not self._api_keys.get(...)
})
if missing_keys:
    raise RuntimeError(...)
```

The `all_pro` strategy's routing context includes T2+T3 backends. Both need keys checked even though `all_pro` only routes to T3 at runtime.

**Required keys:**

| Key | Used by | Provider | Base URL |
|---|---|---|---|
| `DASHSCOPE_API_KEY` | T1, T2 | DashScope (aliyun) | `dashscope.aliyuncs.com` |
| `AICODE007_API_KEY` | T3 | aicode007 | `api.aicode007.com` |

Current `.env` only has `DEEPSEEK_API_KEY` which is not used by any tier config.
