## Lock Scope: NOT Expanded

The `_repo_git_lock` context manager in `local_harness.py` protects only git metadata operations (`git worktree add`, `git worktree remove`, `git worktree prune`). Agent repair execution is NOT inside the lock. This is unchanged from the original design — Phase C2 only moved the lock file location, not the scope.

## Jobs>1 Readiness

The runtime path architecture now supports multi-process execution:
- fcntl.flock files in `/tmp/budgetflow-runtime/locks/` (local fs, no NFS NLM deadlock)
- Worktrees in `/tmp/budgetflow-runtime/worktrees/` (local fs, fast git operations)
- Repo caches in `/tmp/budgetflow-runtime/repos/` (local fs, fast clone)
- Lock scope unchanged (git metadata only, not agent repair)

**Recommendation:** jobs>1 is safe to re-enable from a filesystem perspective. However, before running a paid benchmark with jobs>1:
1. Run a no-paid smoke with `--budget-memory-dry-run` or `--budget-memory-gate-only` to verify path configuration.
2. Run a single-policy dry-run with `--jobs 1` to verify end-to-end path correctness.
3. Then incrementally scale: `--jobs 2` with a small task set before `--jobs N`.

API rate limits remain the primary concern for parallelism, not filesystem contention.

## Review Fixes (2026-06-05)

Three P0 bugs found in review, all fixed:

### P0.1: `runtime.py` repo root off-by-one

**Bug:** `Path(__file__).resolve().parents[4]` from `paper1/src/budgetflow/runtime.py` resolved to `/root/.dev`, not `/root/.dev/AgentOS`.

**Fix:** Added `get_project_root()` (parents[3] → `/root/.dev/AgentOS`) and `get_paper1_root()` (parents[2] → `paper1/`). Updated `resolve_mini_swe_src()` and `resolve_swebench_export_dir()` to use these helpers. Added 4 tests in `TestProjectRoot`.

**Verification:** `resolve_mini_swe_src()` → `/root/.dev/AgentOS/external/mini-swe-agent/src` (not `/Lishun`).

### P0.2: `local_harness.py` legacy repo cache fallback

**Bug:** `repo_dir_for()` silently preferred legacy `paper1/data/repo_cache/` when it existed, bypassing the runtime root migration.

**Fix:** Legacy fallback now gated behind `BUDGETFLOW_USE_LEGACY_REPO_CACHE=1`. Default always returns `{runtime_root}/repos/{slug}`. Added 2 tests in `TestRepoCacheIsolation`.

**Verification:** `repo_dir_for(sympy/sympy)` → `/tmp/budgetflow-runtime/repos/sympy__sympy` by default, even though `paper1/data/repo_cache/sympy__sympy` exists.

### P0.3: Test hygiene — NFS path creation

**Bug:** `test_set_runtime_root_nfs_allowed` called `set_runtime_root("/Lishun/foo/bar", allow_nfs=True)` which tried `mkdir` on the real `/Lishun` path.

**Fix:** Mocked `Path.mkdir` via `monkeypatch.setattr(Path, "mkdir", ...)`. Legacy fallback test redirected `_LEGACY_REPO_CACHE` to `tmp_path` instead of touching real clone dirs. Removed `teardown_module` cleanup that tried to `rmdir` real clone directories.
